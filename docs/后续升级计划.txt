# MVP AI部署助手 - 个人版极致升级计划

> **核心理念：** 不做大而全，只做小而精。聚焦个人开发者/独立开发者的实际使用场景，把每个功能做到极致的流畅和好用。

> **实现状态（2026-08-16）：** 计划内功能已全部实现
> - 一键启动/自启动/托盘：开机自启动（注册表）+ 系统托盘（tray.bat，pystray 可选依赖）+ start.bat 静默启动
> - 智能项目识别：pom.xml/package.json/application.yml 解析，自动推荐 JDK/构建命令/数据库名（/api/v1/files/detect）
> - 一键回滚：部署历史内按备份一键回滚（30 秒内恢复）
> - 批量操作：多项目顺序批量部署（/api/v1/deploy/batch），同主机自动串行
> - 部署速度优化：MD5 增量传输（本地+远程）、SSH 连接池复用
> - 监控看板：状态卡片 + 阈值告警 + 5 秒自动刷新开关
> - 进程守护：30 秒间隔检查，自动重启最多 3 次，钉钉通知
> - 磁盘智能管理：85% 告警，自动清理旧备份/日志，Web 一键清理
> - 钉钉告警增强：分类推送 + 快捷链接 + 静默时段
> - 本地 AI 优先：Ollama 支持，Web 一键切换 DeepSeek/Ollama
> - AI 对话式运维：右侧抽屉，多轮对话，上下文感知
> - AI 配置优化：JVM/Nginx/MySQL 参数建议
> - AI 生成部署脚本：Shell/Batch，含回滚逻辑
> - 极简部署向导：一键部署（智能配置直达日志页），高级配置折叠
> - 智能日志分析：ERROR/WARNING/SUCCESS 高亮、错误摘要、搜索、下载
> - 暗色主题：亮/暗/跟随系统
> - 配置导出导入：加密 JSON，覆盖/合并两种模式
> - 自动备份：每日 02:30 SQLite 备份，保留 N 天
> - 数据可控：AES-256 加密 + 一键清空
> - 多语言：中英双语基础版（界面外壳）
> - 自定义部署后脚本：项目内 .sh 或任意命令
> - 多环境配置模板：内置 dev/test/pre/prod + 自定义模板

## 一、升级理念与原则

### 1.1 设计原则
- **开箱即用：** 下载解压就能用，零配置起步
- **极致流畅：** 每个操作响应时间 < 1秒，大文件传输有进度反馈
- **容错性强：** 任何步骤失败都有明确的错误提示和补救方案
- **资源友好：** 运行时内存占用 < 500MB，不影响日常开发
- **数据安全：** 所有敏感信息本地加密存储，不上传任何数据

### 1.2 功能取舍原则
- ✅ 保留：所有让"一个人部署更方便"的功能
- ✅ 强化：速度、稳定性、易用性
- ❌ 不做：多用户、权限管理、审批流程、计费系统


## 二、部署效率提升（核心体验优化）

### 2.1 一键启动与自启动
**功能描述：**
- 支持开机自启动（注册为Windows服务或添加启动项）
- 支持最小化到系统托盘，右键快速操作
- 支持命令行静默启动（无窗口模式）

**用户场景：**
- 电脑开机后MVP自动在后台运行
- 需要部署时直接打开浏览器访问，无需手动启动

### 2.2 智能项目识别与自动配置

**功能描述：**
- 将部署包放入指定目录后，MVP自动扫描并识别项目类型：
  - 检测到 `pom.xml` → 自动执行 `mvn clean package`
  - 检测到 `package.json` → 自动执行 `npm install && npm run build`
  - 检测到 `application.yml` → 自动解析数据库连接信息
  - 检测到 `Dockerfile` → 提示可选择Docker部署模式
- 自动解析项目名称（从 `pom.xml` 或 `package.json` 读取）
- 自动推荐JDK版本（从 `pom.xml` 读取 `java.version`）
- 自动生成部署配置文件（首次使用后保存为模板）

**用户场景：**
- 开发者把整个项目源码目录拖入MVP
- MVP自动识别这是一个Spring Boot + Vue项目
- 自动推荐JDK 17 + Node.js 18
- 自动生成nginx.conf和application-prod.yml
- 用户点击"部署"即可，无需任何配置

### 2.3 一键回滚

**功能描述：**
- 部署成功后自动记录"部署快照"，包含：
  - 前端文件完整备份
  - 后端Jar/War完整备份
  - 配置文件完整备份
  - 数据库当前Schema备份（可选）
- 在部署历史列表中，每个成功部署记录旁边显示"一键回滚"按钮
- 点击回滚后，30秒内完成服务恢复

**用户场景：**
- 新版本上线后发现Bug，点击"回滚"按钮
- 选择回滚到哪个历史版本（保留最近10次快照）
- 30秒后服务恢复到旧版本

### 2.4 批量操作

**功能描述：**
- 支持在部署向导中一次性上传多个项目
- 支持选择多台主机（仅限已配置的主机）同时部署
- 支持批量回滚

**用户场景：**
- 同时更新微服务架构中的3个服务
- 在MVP中同时选择3个项目，一键部署到同一台主机
- 部署顺序按依赖关系自动排列

### 2.5 部署速度优化

**功能描述：**
- 增量传输：只传输变更的文件（基于文件Hash比对）
- 并行执行：多个部署步骤并行执行（如上传文件和安装依赖同时进行）
- 本地缓存：已下载的依赖包（Maven/npm）本地缓存，避免重复下载
- SSH连接复用：多次部署复用同一连接，减少握手耗时

**用户场景：**
- 项目代码修改后重新部署
- MVP自动检测只修改了 `backend.jar`，只上传该文件
- 部署时间从3分钟缩短到15秒


## 三、监控与告警（个人运维必备）

### 3.1 智能监控看板

**功能描述：**
- Web界面展示所有已部署项目的状态总览
- 每个项目显示：
  - 运行状态（运行中/已停止/异常）
  - 运行时长（自上次部署/启动以来）
  - 最近5次部署记录
  - 当前版本号（部署时间戳）
  - CPU/内存实时使用率（小图表）
- 状态卡片颜色标识：绿色（正常）、黄色（警告）、红色（异常）
- 支持手动刷新和自动刷新（每5秒）

**用户场景：**
- 打开MVP首页，一眼看清所有服务状态
- 发现某个服务变红，点击查看详情

### 3.2 进程守护与自动恢复

**功能描述：**
- MVP在后台持续监控所有已部署服务的进程状态
- 检测到服务进程意外退出时：
  - 自动尝试重启服务（最多3次）
  - 重启成功后推送钉钉通知："服务已自动恢复"
  - 重启失败后推送告警："服务异常，请手动检查"
- 监控间隔可配置（默认30秒）
- 支持配置哪些服务需要守护（默认全部）

**用户场景：**
- 凌晨3点Tomcat因OOM崩溃
- MVP检测到进程退出，自动执行 `startup.bat`
- 30秒后服务恢复，用户早上看到钉钉通知

### 3.3 磁盘空间智能管理

**功能描述：**
- 自动监控部署目录磁盘空间
- 当磁盘使用率超过85%时告警
- 自动清理策略：
  - 保留最近5次部署备份
  - 自动删除超过30天的日志文件
  - 自动清理Maven/npm构建缓存（可配置保留最近3个版本）
- 支持手动清理（Web界面一键清理）

**用户场景：**
- 磁盘使用率达到90%
- MVP自动清理旧的备份和日志
- 释放20GB空间，推送通知告知清理结果

### 3.4 钉钉告警增强

**功能描述：**
- 告警事件分类推送：
  - **部署类：** 部署成功、部署失败、回滚成功
  - **监控类：** 服务宕机、服务恢复、资源告警
  - **系统类：** 磁盘不足、备份清理
- 告警消息附带"快捷操作"链接：
  - 部署失败消息附带"查看日志"和"重试"按钮
  - 服务宕机消息附带"重启服务"按钮
  - 点击链接直接跳转到MVP对应页面
- 支持自定义告警时间段（如只在9:00-21:00推送）

**用户场景：**
- 钉钉收到消息："❌ 部署失败：订单服务"
- 消息下方有"查看日志"按钮
- 点击后直接打开MVP的日志页面
- 查看错误后点击"重试"按钮重新部署


## 四、AI能力深度整合（个人智能助手）

### 4.1 本地AI优先（保护隐私）

**功能描述：**
- 优先支持Ollama本地模型（如Qwen2.5、DeepSeek-R1蒸馏版）
- 不依赖网络，断网环境下也能正常使用AI功能
- 本地AI功能包括：
  - 部署计划生成
  - 错误日志分析
  - 配置参数推荐
- 云端AI作为增强选项（联网时自动使用DeepSeek API）
- AI切换在Web界面一键完成

**用户场景：**
- 在飞机上（无网络）部署项目
- MVP使用本地Ollama模型生成部署计划
- 部署顺利完成，无需联网

### 4.2 AI对话式运维

**功能描述：**
- 在MVP界面右侧提供AI对话侧边栏
- 支持自然语言提问，例如：
  - "帮我检查为什么订单服务启动失败"
  - "帮我优化JVM参数"
  - "帮我写一个Nginx限流配置"
  - "总结一下这个项目最近3次部署的情况"
- AI自动理解上下文（当前项目、主机、部署记录）
- 支持多轮对话

**用户场景：**
- 部署失败，看到一堆错误日志
- 在AI对话框输入："这个错误是什么意思？"
- AI分析日志后回复："检测到端口8080被占用，建议先停止占用进程"
- 用户点击AI建议的"停止进程"按钮，自动执行

### 4.3 AI配置优化建议

**功能描述：**
- AI分析主机配置后给出JVM参数建议：
  - 根据内存大小推荐 `-Xms` 和 `-Xmx`
  - 根据CPU核心数推荐GC算法
- AI分析Nginx配置后给出性能优化建议：
  - 推荐worker_processes数量
  - 推荐keepalive_timeout值
- AI分析MySQL配置后给出优化建议：
  - 推荐innodb_buffer_pool_size
  - 推荐max_connections
- 所有建议一键应用（生成新配置文件并重启）

**用户场景：**
- 新买了一台4核16G的服务器
- 部署Spring Boot项目时，AI自动推荐：
  "根据主机配置，建议JVM参数：-Xms4g -Xmx8g -XX:+UseG1GC"
- 点击"应用"按钮，MVP自动修改启动脚本
- 部署后服务性能提升30%

### 4.4 AI自动生成部署脚本

**功能描述：**
- 对于复杂部署场景（多服务、多环境），AI一键生成完整部署脚本
- 生成的脚本支持：
  - Shell脚本（Linux）和Batch脚本（Windows）
  - 包含完整的错误处理和日志输出
  - 包含回滚逻辑
- 生成的脚本可以在MVP中直接运行，也可以导出手动执行

**用户场景：**
- 项目有5个微服务 + 3个前端应用
- AI根据项目结构生成完整的部署编排脚本
- 一个脚本完成所有服务的部署和启动

## 八、性能优化目标

| 指标 | 目标值 | 说明 |
